# `standards`

**Engineering standards.**

## Responsibility

Mechanically enforced rules. A standard that depends on human discipline is a
preference, not a standard: every entry names the verification method that enforces it.

## What may not enter

- A standard with no verification method.
- Guidance, style preferences, or advice. Those belong in a specification.
