# STD-10 — Releases are immutable

Re-publishing an existing release version is rejected ([ADR-0006](../adr/ADR-0006.md),
[ADR-0010](../adr/ADR-0010.md)). Standing changes through
[ADR-0024](../adr/ADR-0024.md); bytes never do.
