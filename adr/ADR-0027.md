# ADR-0027 — Bitemporal migration procedure

## Context

Introducing bitemporality ([ADR-0004](ADR-0004.md)) is the highest-risk change in the plan:
it alters the observation schema, forces a new dataset release, and requires re-deriving
every published figure. It blocks most later work. It had no rollback.

## Decision

Five stages, each with an exit criterion and a rollback.

**S1 — Additive schema and dual write.** Add nullable `ingest_time`. New ingests write both
times; historical rows remain NULL ([ADR-0022](ADR-0022.md)) — **no backfill**. Nothing reads
it yet. *Rollback: ignore the column; it is additive.*

**S2 — Shadow read.** The engine reads the bitemporal store in parallel with the current
path; outputs are compared field by field; divergences logged with run IDs. Nothing is
published from the shadow path. *Rollback: disable shadow; zero user-visible effect.*

**S3 — Validation.** Exit criterion: **zero divergence across all published evaluations for
three consecutive full runs at class `EXACT`.** Any divergence halts the migration and is
investigated as a defect — it is never tolerated or explained away. *Rollback: remain on the
current path indefinitely. S3 has no deadline.*

**S4 — Cutover.** Bitemporal store becomes authoritative; a new dataset release is
published; all figures re-derived; the evidence gate must pass; the previous release is
marked `DEPRECATION` per [ADR-0024](ADR-0024.md). *Rollback: re-point publication at the
previous release digest — a configuration change, not a restore. **Rehearsed before cutover
is declared complete.***

**S5 — Decommission.** Remove the legacy read path only after **one full acquisition cycle**
with no rollback. *Rollback: none. This is the point of no return, deliberately placed after
a full cycle of production use.*

## Consequences

- The highest-risk phase is reversible at every stage but the last.
- Shadow running doubles evaluation cost for a time-boxed period.

## Verification

INTG and INSP per VVMP §2.1: the divergence report, plus recorded evidence of the rollback
rehearsal.
