# ADR-0015 — Static publication, isolated live surfaces

## Context

Evidence surfaces and live surfaces have different availability contracts, different deploy
cadences, and different failure consequences. An outage of a live view must not affect the
durability of published evidence.

## Decision

Evidence is published as static files. Any live surface, if one is ever built, is a separate
application with a separate deployment.

Evidence routes ship zero JavaScript, enforced by per-route byte budgets.

## Consequences

- Published evidence has maximum durability and minimum operational cost.
- Interactive features on evidence surfaces are forbidden by budget, not by preference.

## Verification

INTG per VVMP §2.1: the byte-budget gate, plus review of deployment topology.
