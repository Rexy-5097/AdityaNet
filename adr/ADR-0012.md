# ADR-0012 — Evidence binding and consistency gate

## Context

"Our figures are traceable" is a convention until something mechanically prevents a typed
number from reaching a page.

## Decision

Binding is mechanical in both directions.

**Inbound:** a component that displays a measured quantity accepts a measurement **key**,
never a value. There is deliberately no `value` parameter, so a caller cannot pass a figure
and a figure cannot reach a page without existing in an artifact first.

**Outbound:** each rendered value is marked in the output with the key it came from. After
the build, a gate re-reads the artifacts from storage, resolves each pointer, and compares
against what is present in the rendered output. Drift **fails the build**.

## Consequences

- No number on a published surface is typed by a person.
- Coverage is bounded by what is pointer-bound; values carried verbatim inside prose tables
  trace to a report rather than a pointer. Coverage claims must state this
  (VVMP §10.2, U-4).

## Verification

INTG and ARCH per VVMP §2.1: deliberate drift fails the build; a numeric literal in a
publication template fails the template gate.
