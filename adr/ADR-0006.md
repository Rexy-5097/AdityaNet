# ADR-0006 — Dataset releases are immutable

## Context

A dataset that changes under a fixed name cannot be cited, and any result computed against
it becomes unreproducible.

## Decision

A DatasetRelease is immutable and digest-addressed. Re-publishing an existing version is
rejected. The bytes of a release never change and are never deleted.

Where a release is later found to be wrong, its **standing** changes through
[ADR-0024](ADR-0024.md). Its bytes do not.

## Consequences

- Releases are citable units.
- Correcting an error requires publishing a new release plus a supersession record, which
  is more work than editing in place, and is the only version that preserves auditability.

## Verification

INTG and PROP per VVMP §2.1: a re-freeze rejection test and a byte-immutability property.
