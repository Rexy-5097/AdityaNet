# ADR-0022 — Unknown ingest time is NULL

## Context

A proposed migration would have backfilled `ingest_time` with the dataset freeze timestamp,
"flagged as imputed". That violates [ADR-0017](ADR-0017.md) on the most provenance-critical
field in the system. A flag does not convert a fabrication into a measurement.

## Decision

1. `ingest_time` is **nullable**. `NULL` has exactly one meaning: *unknown — this observation
   predates bitemporal capture.* It is never fabricated, defaulted, or inferred.
2. The leakage gate applies only where a Protocol declares an as-of constraint, via
   `requires_bitemporal`:
   - `true` — observations with `ingest_time = NULL` are **excluded**; the gate is
     enforceable by construction.
   - `false` — NULL is permitted, and the Evaluation records `leakage_gate_applied = false`.
3. Limitation [L-11](../specs/limitations/L-11.md) publishes the consequence.

## Consequences

- No provenance value is fabricated.
- Forecasting claims are structurally prevented from resting on data whose availability
  cannot be established.
- Historical data supports detection claims but not forecasting claims.

## Verification

PROP and INTG per VVMP §2.1: a no-backfill property test, and integration tests for both
protocol modes.
