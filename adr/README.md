# `adr`

**Architecture decision records.**

## Responsibility

One file per citable ADR identifier. Accepted ADRs are immutable: a decision that no
longer holds is superseded by a new ADR and moved to superseded/, never edited. See
index.md for the current corpus.

## What may not enter

- Edits to an accepted ADR. Supersede instead.
- More than one file per citable ID.
- A document without the five front-matter keys, other than index.md and README.md.
