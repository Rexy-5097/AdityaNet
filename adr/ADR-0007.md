# ADR-0007 — Ground truth is a separate versioned context

## Context

Labels come from a different mission, under a different authority, and are revised after
the fact. NOAA SWPC edits events. Conflating labels into the dataset means a label revision
silently changes historical scores.

## Decision

Ground truth is its own bounded context. A **LabelRelease** is an immutable, digest-addressed
snapshot of an external authority's output at a recorded ingest time. A revision produces a
**new** release; the prior release is retained and remains addressable.

Every Evaluation records which LabelRelease it scored against, by digest. Pinning by
"latest" is forbidden.

## Consequences

- Historical scores remain valid and reproducible across catalog revisions.
- Two registries exist where a simpler design would have one. The cost is accepted.

## Verification

ARCH and INTG per VVMP §2.1: a context-import test, and an integration test in which a
revised catalog yields a second release with both retained.
