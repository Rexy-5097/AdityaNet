# ADR-0017 — Missing data is never imputed

## Context

Zero is a valid measurement of a count rate. Substituting zero, a mean, or an interpolated
value for absence destroys the distinction between "observed to be low" and "not observed",
irreversibly and invisibly.

## Decision

Missing values are preserved as missing on every path. No fill, no interpolation, no
zero-substitution, no forward-fill, no default.

This applies to provenance fields as strictly as to measurements. See
[ADR-0022](ADR-0022.md), which forbids fabricating an unknown `ingest_time`.

## Consequences

- Downstream code must handle missingness explicitly rather than assuming density.
- Some analyses become harder. That is the correct cost.

## Verification

PROP and STAT per VVMP §2.1: a no-imputation property test over generated inputs, plus a
static ban on fill and interpolate calls within canonicalisation.
