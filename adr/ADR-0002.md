# ADR-0002 — Domain model and ubiquitous language

## Context

Two naming errors were identified before implementation. First, a vocabulary built around
`Model` structurally privileges machine learning, and the winning method in this domain is
a threshold on a count rate — not a model. Second, "Measurement" was used to mean both a
physical measurement and a number displayed on a page.

## Decision

The ubiquitous language is fixed as follows.

- **`Method`**, never `Model`. A threshold detector is a Method.
- **`Observation`** is a physical measurement. **`Evidence Binding`** is a published value
  bound to an artifact. The term "Measurement" is retired.
- First-class entities: Artifact, ProvenanceRecord, Run, Mission, Instrument, Source,
  Observation, Dataset, DatasetRelease, LabelSource, LabelRelease, Event, Method,
  MethodRelease, Prediction, Protocol, EnvironmentRelease, Evaluation, Score, Interval,
  Claim, EvidenceBinding, Limitation, Supersession.
- Rejected as entities: Model, Ground Truth (= LabelRelease), Benchmark (= Protocol plus a
  set of Evaluations), Experiment (= Run producing a MethodRelease), Detection (= Prediction
  under a detection Protocol), Uncertainty (= Interval value object), Version (an attribute).

## Consequences

- The vocabulary never has to be rewritten if a non-ML method continues to win.
- Renaming later, after a registry exists, would be expensive; doing it at inception is free.

## Verification

STAT and MAN per VVMP §2.1: an identifier scan rejects `Model` in domain code, and a
glossary review is part of manual review.
