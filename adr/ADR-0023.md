# ADR-0023 — Storage tiers

## Context

An architecture whose foundational storage layer is unnamed, unowned and unfunded is not
implementable. Interrogating the requirement removed most of it: the integrity requirement
for raw archives is that they be *identified*, not *held*.

## Decision

| Tier | Content | System of record | Cost |
|---|---|---|---|
| **0** | Raw source archives (~21 GB) | **Not stored.** Digest plus retrieval descriptor only | Zero |
| **1** | Canonical dataset and label releases (~0.6 GB/release) | Zenodo — versioned, DOI-issued, preservation-oriented | Zero |
| **2** | Derived artifacts, evidence payloads, manifests | Git | Zero |

Local raw copies are **evictable caches**, never the system of record. Any stage must be
able to re-acquire from the descriptor. Tier 0 bytes are never redistributed.

**Lifecycle:** Tier 0 cache evictable; Tier 1 permanent; Tier 2 artifacts referenced by an
Evidence Binding permanent; unreferenced run artifacts pruned after 90 days.

**Fallback** if Zenodo is unavailable: repository release attachments with digests in git.
This degrades citability — no DOI — and the degradation is published rather than hidden.

**Budget assumption: zero recurring cost.** If this becomes false, this ADR must be
superseded before spend is committed.

## Consequences

- Another organisation's data is not redistributed.
- Long-term durability rests on a third-party commitment, verifiable by inspection only
  (VVMP §10.2, U-3).

## Verification

INTG and INSP per VVMP §2.1: deposit digest match; a Tier 0 non-redistribution gate;
inspection of the host's preservation policy.
