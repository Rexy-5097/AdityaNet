# ADR-0009 — Evaluation as a pure function of four pinned inputs

> **SUPERSEDED by [ADR-0021](../ADR-0021.md).** Retained unedited. The decision below was
> found to be false during Architecture Review Board review: an Evaluation also depends on
> the execution environment, which this ADR left unpinned.

## Decision (as originally accepted)

    Evaluation = f(MethodRelease, DatasetRelease, LabelRelease, Protocol)

Identical inputs must produce identical Scores, forever. Determinism of the execution
environment is enforced by engineering standard STD-08 (seeds, hash seed, thread counts).

## Why it was superseded

A standard is not an input. Results depend on library versions, BLAS implementation, thread
count, reduction order and CPU architecture. Re-running under a different numeric library
would move published scores in the low decimals with no gate firing, while the architecture
asserted reproducibility.

[ADR-0021](../ADR-0021.md) adds `EnvironmentRelease` as a fifth digest-addressed input and
introduces reproduction classes, because bit-identity across CPU architectures cannot be
guaranteed and claiming it would be a new unsupported assertion.
