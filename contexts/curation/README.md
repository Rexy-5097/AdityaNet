# `contexts/curation`

**Freeze observations into citable releases.**

## Responsibility

Immutable, digest-addressed DatasetReleases, their manifests, and the retention policy.

## What may not enter

- Any awareness of how the data will be used. Curation must not optimise for the benchmark.
- Mutation or re-publication of an existing release version.
- Deletion of released bytes. Standing changes through supersession; bytes do not.
