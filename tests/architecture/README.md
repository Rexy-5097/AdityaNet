# `tests/architecture`

**The architecture, as executable assertions.**

## Responsibility

Import direction, forbidden names, kernel isolation and repository structure. These
convert the context map from a diagram into a build failure.

## What may not enter

- An assertion without a deliberate-violation counterpart.
- An exclusion that does not expire when its justification does.
